If you want to implement the sorting algorithm yourself (e.g. for learning purposes), here is an example of a simple bubble sort implementation:
```
def sort_list_bubble(lst):
    n = len(lst)
    for i in range(n-1):
        for j in range(0, n-i-1):
            if lst[j] > lst[j+1]:
                lst[j], lst[j+1] = lst[j+1], lst[j]
    return lst
```
This function works by repeatedly iterating through the list, comparing adjacent elements and swapping them if they are in the wrong order. This process is repeated until the entire list is sorted.

```python
def sort_list_merge(lst):
    """
    Sorts a list using the merge sort algorithm.

    Args:
        lst (list): The list to be sorted.

    Returns:
        list: A new list containing the same elements in sorted order.
    """

    # Base case: If the list has one or zero elements, it's already sorted.
    if len(lst) <= 1:
        return lst

    # Find the middle index to split the list into two halves.
    mid = len(lst) // 2

    # Recursively sort the left and right halves.
    left_half = sort_list_merge(lst[:mid])
    right_half = sort_list_merge(lst[mid:])

    # Merge the sorted left and right halves.
    return merge(left_half, right_half)


def merge(left, right):
    """
    Merges two sorted lists into a single sorted list.

    Args:
        left (list): The first sorted list.
        right (list): The second sorted list.

    Returns:
        list: A new list containing all elements from both lists in sorted order.
    """

    # Initialize an empty list to store the merged result.
    merged = []

    # Initialize indices to track the current position in both lists.
    left_index = 0
    right_index = 0

    # Merge smaller elements first.
    while left_index < len(left) and right_index < len(right):
        if left[left_index] <= right[right_index]:
            merged.append(left[left_index])
            left_index += 1
        else:
            merged.append(right[right_index])
            right_index += 1

    # Append any remaining elements from the left or right lists.
    merged.extend(left[left_index:])
    merged.extend(right[right_index:])

    return merged

```

**Merge Sort Algorithm Overview**

Merge Sort is a stable sorting algorithm that works by recursively dividing the input list into smaller sublists, sorting each sublist, and then merging the sorted sublists back together to produce the final sorted list. The key benefits of Merge Sort are:

* **Efficiency**: Merge Sort has a time complexity of O(n log n) in the worst case, making it suitable for large datasets.
* **Stability**: Merge Sort preserves the relative order of equal elements, ensuring that the sorted list maintains the same order as the original list for elements with the same value.

```python
def sort_list(lst):
    """
    Sorts a list in ascending order.
    
    Args:
        lst: The list to sort
        
    Returns:
        A new sorted list
    """
    return sorted(lst)

# Example usage
```

If you want to sort the list in place (modifying the original list), you can use:

```python
def sort_list_in_place(lst):
    """
    Sorts a list in place (modifies the original list).
    
    Args:
        lst: The list to sort
    """
    lst.sort()

# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
sort_list_in_place(numbers)
print(numbers)  # Output: [11, 12, 22, 25, 34, 64, 90]
```

You can also add options for descending order:

```python
def sort_list(lst, reverse=False):
    """
    Sorts a list in ascending or descending order.
    
    Args:
        lst: The list to sort
        reverse: If True, sorts in descending order
        
    Returns:
        A new sorted list
    """
    return sorted(lst, reverse=reverse)

# Descending order
numbers = [64, 34, 25, 12, 22, 11, 90]
print(sort_list(numbers, reverse=True))  # Output: [90, 64, 34, 25, 22, 12, 11]
```
